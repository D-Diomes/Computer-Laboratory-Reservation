## Setup and Run
1. python -m venv .venv
2. .venv\Scripts\activate | source .venv/bin/activate
3. Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass (if the ".venv\Scripts\activate" gives error, run this code first)
4. pip install -r requirements.txt
